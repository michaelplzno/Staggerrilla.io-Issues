# Staggerrilla.io — Public Issues & Suggestions

This is the public issue tracker and suggestion board for [Staggerrilla.io](https://staggerrilla.io), the Twitch-controlled live Bleep game.

The production code remains private. This repository exists so anyone with a GitHub account can report a problem or suggest an improvement.

- [Report a bug](https://github.com/michaelplzno/Staggerrilla.io-Issues/issues/new?template=bug-report.yml)
- [Suggest a feature](https://github.com/michaelplzno/Staggerrilla.io-Issues/issues/new?template=feature-request.yml)
- [View existing issues](https://github.com/michaelplzno/Staggerrilla.io-Issues/issues)
- [Watch Staggerrilla on Twitch](https://www.twitch.tv/staggerrilla)

## Before submitting

1. Search existing issues so we do not split the same conversation.
2. Submit one problem or suggestion per issue.
3. Include enough detail to understand the desired result.
4. Never post Steam keys, access tokens, passwords, private account data, or other secrets.

## Project-owner discretion

Issues are proposals, not commitments or a public roadmap. Staggerrilla / Silverware Games decides, in its sole discretion, what is investigated, designed, built, changed, postponed, rejected, or removed. An issue may be closed for any reason, including scope, safety, cost, technical fit, creative direction, duplication, or lack of current interest.

Submitting an idea does not create a promise of implementation, compensation, credit, employment, partnership, or continued discussion.
